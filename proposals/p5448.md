## Proposal

-   Carbon `iN` types will map to C++ `intN_t` types and the other way around
    (C++ to Carbon).
-   The C++ standard integer types (`signed char`, `short`, `int`) will map to
    the corresponding Carbon `iN` type, as the `intN_t` types are typically
    aliases for the standard integer types.
-   `long`, `long long`, `long double` in C++ will map to distinct (new) Carbon
    types.
-   Correspondingly for the unsigned types.
-   `float` will map to `f32`; `double` to `f64`.

## Details

This table shows a bidirectional mapping (Carbon <-> C/C++).

| Carbon                        | C/C++                        |
| ----------------------------- | ---------------------------- |
| `Void`                        | `void`                       |
| `Bool`                        | `bool`                       |
| `i8`                          | `int8_t`, `signed char`      |
| `u8`                          | `uint8_t`, `unsigned char`   |
| `i16`                         | `int16_t`, `short`           |
| `i32`                         | `int32_t`, `int`             |
| `i64`                         | `int64_t`                    |
| `i128`                        | `int128_t`                   |
| `u8`                          | `uint8_t`, `unsigned char`   |
| `u16`                         | `uint16_t`, `unsigned short` |
| `u32`                         | `uint32_t`, `unsigned int`   |
| `u64`                         | `uint64_t`                   |
| `f32`                         | `float`                      |
| `f64`                         | `double`                     |
| `Core.Cpp.long`               | `long`                       |
| `Core.Cpp.long_long`          | `long long`                  |
| `Core.Cpp.unsigned_long`      | `unsigned long`              |
| `Core.Cpp.unsigned_long_long` | `unsigned long long`         |
| `Core.Cpp.long_double`        | `long double`                |

Note: The names `Core.Cpp.T` represent new Carbon types that don't exist at the
moment and their precise names are still to be decided.

### Unsupported types

-   C++:
    -   `floatN_t` (fixed-width floating-point types) - will wait to see how
        their usage evolves
    -   `char8_t`, `char16_t`, `char32_t`, `wchar_t`
